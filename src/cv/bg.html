Laravel / PHP пакети
github.com/givanov95

Седем repo-та с над 40 тагнати версии — шест пакета в Packagist и два съпътстващи Vue пакета в npm — които използвам в собствените си проекти:

  • laravel-data-table — server-side DataTable builder за Laravel с Vue 3 + Inertia frontend: търсене, сортиране, колони от релации и преводими колони, custom query hooks, slots за собствени клетки. Packagist + npm
  • laravel-roles-permissions-crud — админ CRUD за роли и права върху spatie/laravel-permission: контролери, form requests, route macro и готови Vue 3 компоненти. Packagist + npm
  • typed-http — типизиран, обектно-ориентиран HTTP клиент за PHP 8.2+ върху PSR-18: един Connector за API, един Request клас за заявка, типизирани DTO отговори, автентикация, retry и JSON / form / multipart / XML тела; опционален Laravel bridge. Packagist
  • laravel-translations — многоезична инфраструктура за Laravel + Inertia + Vue: полиморфни преводи, trait HasTranslation, кеширан translator service и locale middleware. Packagist
  • laravel-attachments — полиморфни прикачени файлове и снимки с traits HasImages / HasFiles и поддръжка на няколко секции. Packagist
  • laravel-git-hooks — Composer plugin, който инсталира pre-commit проверки за Laravel + Vite приложения. Върви със ci-workflows — преизползваеми GitHub Actions workflows, които налагат същите проверки в CI. Packagist
